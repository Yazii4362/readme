BRADINGO

8년 6개월의 대학생활을 5개의 퀘스트로 다시 경험하는 인터랙티브 졸업 축하 웹

친구의 졸업을 축하하기 위해 실제 추억과 학교생활을 게임형 코스와 퀴즈로 재구성한 개인화 웹 경험. 듀오링고의 학습 코스 구조를 차용해, 축하 메시지를 읽는 경험이 아니라 직접 진행하고 완료하는 경험으로 설계했다.

01 — Context

개요

프레임워크 없이 바닐라 JavaScript(ES 모듈)로 구현했고, 한국어·영어·일본어·스페인어 4개 언어를 지원한다. 모바일 우선으로 설계해 GitHub Pages에 배포했다.

02 — Problem

읽는 축하로는 기억이 전달되지 않았다

일반적인 롤링페이퍼나 사진 모음은 축하 메시지를 수동적으로 읽고 끝나는 경험이다. 한 사람의 8년 6개월이라는 긴 대학생활과 친구들 사이에 쌓인 기억을 그 형식에 담기에는 전달력이 부족했다.

03 — Solution

5개 노드의 퀘스트로 재설계

졸업까지의 경험을 5개 노드의 퀘스트 구조로 재설계했다. 코스 맵을 중심 허브로 두고 퀴즈·추억 콘텐츠·축하 메시지·엔딩이 순차적으로 해금되도록 구성했다.

병건이와 이루매 두 캐릭터를 직접 디자인하고, UOS Blue를 기반으로 한 독자적인 디자인 시스템을 만들었다. 노드의 완료·활성·잠금 세 가지 상태를 색과 형태로 구분해, 사용자가 자신의 진행 상황을 한눈에 파악할 수 있게 했다.

Course map Quiz Memory Message Ending
04 — Outcome

Graduation Quest

단순한 축하 페이지가 아니라 사용자가 직접 진행하고 완료하는 개인화된 Graduation Quest 웹 경험으로 완성했다. 게임형 인터랙션 시스템을 기획부터 구현까지 혼자 설계한 프로젝트다.
